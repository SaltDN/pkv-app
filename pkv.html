Kết nối GitHub

Mỗi thiết bị nhập một lần. Thông tin chỉ lưu trong trình duyệt của thiết bị đó, không nằm trong code. Dữ liệu đẩy lên kho riêng (private), được mã hóa nếu bạn đã đặt mật khẩu khóa. Chưa cần dùng thì cứ bỏ qua, ghi chú vẫn lưu trên máy này.

Cách tạo kho và token
  1. GitHub → New repository, đặt tên (ví dụ pkv-data), chọn Private, tick Add a README.
  2. Avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → chọn đúng kho vừa tạo.
  4. Permissions → Repository permissions → Contents: Read and write (không cần quyền nào khác).
  5. Chọn hạn dùng, bấm Generate token, chép token (chỉ hiện một lần) và dán vào ô bên dưới.
